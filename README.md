# Sana Rafique — Portfolio

A responsive one-page portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation
- `images/` — optional project/profile images

## GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload these files.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → /root**.
5. Save and wait for the site to publish.

## Before publishing
Replace the GitHub and LinkedIn placeholder links in `index.html` with your real profile URLs. Add project screenshots if desired.
