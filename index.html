About me

I'm Sana Rafique

A WordPress Developer with 3.5+ years of experience building responsive, fully customized WordPress websites, WooCommerce stores and business web solutions. My work spans complete WordPress development — custom themes and plugins, page builders and custom sections, WooCommerce, APIs and third-party integrations, hosting and domain management, website migrations, troubleshooting, SEO and performance optimization.

I work across the full WordPress stack — theme and template development, custom plugins, PHP and MySQL, REST APIs and third-party integrations, alongside the frontend build itself. That means I can take a project from design file to a live, optimized, well-maintained website.

Academically, I hold an MCS (Master of Computer Science) from Virtual University of Pakistan, which gave me the computer-science grounding behind the practical work — programming fundamentals, databases and software design. Alongside client work I am now expanding into Artificial Intelligence, Machine Learning and Microsoft Azure, including Azure AI Fundamentals (AI-901), Responsible AI practices, Microsoft Copilot Studio and GitHub Copilot.
